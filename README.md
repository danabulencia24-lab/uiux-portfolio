# UI/UX Portfolio

## Files
- `index.html` — portfolio structure
- `style.css` — all styling
- `script.js` — navigation and case-study interactions

## Run in VS Code
1. Open this folder in VS Code.
2. Open `index.html`.
3. Right-click the file and choose **Open with Live Server** if you have the Live Server extension.
4. Or double-click `index.html` to open it directly in your browser.

The original design/content was separated into HTML, CSS, and JavaScript without changing the supplied portfolio structure.
