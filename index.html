MOBILE APP · UI/UX DESIGN

FitTrack — Fitness Tracker Mobile App

A user-centered mobile fitness experience that turns workout logging, progress tracking, and goal-setting into a fast, motivating daily habit.

Role UI/UX Design
Platform iOS & Android
Tools Figma, FigJam, Photoshop
Timeline 4 weeks
01 / OVERVIEW

Overview

FitTrack helps everyday gym-goers plan workouts, log sets, and track progress without friction, replacing scattered spreadsheets and sticky notes.

02 / PROBLEM

The Problem

Beginners abandon fitness apps within two weeks because logging a single workout takes too many taps, and progress isn't visible enough to feel motivating.

03 / GOALS

Goals

  • Cut workout-logging time to under 10 seconds per set
  • Surface weekly progress at a glance
  • Keep first-time setup under 2 minutes
04 / RESEARCH

User Research

Interviewed 8 gym members and reviewed app-store feedback across 3 competitor apps to map logging friction and drop-off points.

05 / RESULTS

Results

10s

Average time to log a set

5/5

Testers finished onboarding

4

Core navigation tabs

WEB UI/UX DESIGN · DASHBOARD

Student Management System

A clear, role-aware dashboard that lets school staff manage enrollment, grades, and attendance without digging through spreadsheets.

Role UI/UX Design
Platform Web Desktop
Tools Figma, FigJam, Illustrator
Timeline 5 weeks
01 / OVERVIEW

Overview

A web dashboard for school registrars and teachers to manage student records, attendance, and grades in one place.

02 / PROBLEM

The Problem

Staff maintained separate spreadsheets for grades, attendance, and enrollment, causing duplicate data entry and inconsistent reports.

03 / GOALS

Goals

  • Unify records into a single dashboard
  • Reduce time spent generating reports
  • Keep the interface usable for non-technical staff
04 / RESEARCH

User Research

Shadowed a registrar's office for a day and interviewed 4 teachers about their weekly reporting routine.

05 / RESULTS

Results

3

Clicks to record attendance

1

Dashboard replacing multiple spreadsheets

WEB DESIGN · E-COMMERCE

E-Commerce Website

A responsive online store redesign focused on product discovery and a friction-free checkout.

Role Web / UI Design
Platform Responsive Web
Tools Figma, Photoshop, Illustrator
Timeline 6 weeks
01 / OVERVIEW

Overview

A responsive e-commerce site redesign focused on product discovery and a friction-free path to checkout.

02 / PROBLEM

The Problem

The original store had a 4-step checkout and unclear product filtering, leading to a high rate of abandoned carts.

03 / GOALS

Goals

  • Reduce checkout to 2 steps
  • Improve filter discoverability
  • Keep mobile conversion on par with desktop
04 / RESEARCH

User Research

Analyzed funnel drop-off data and ran 6 usability tests on the existing checkout flow.

05 / RESULTS

Results

40%

Fewer checkout steps

2

Checkout steps

WEB APPLICATION · DASHBOARD

Restaurant Management System

A dashboard that gives restaurant staff a single, clean view of orders, tables, and inventory during service.

Role UI/UX Design
Platform Web / Tablet
Tools Figma, FigJam, Photoshop
Timeline 5 weeks
01 / OVERVIEW

Overview

A back-of-house web app for restaurant staff to manage live orders, table status, and inventory in real time.

02 / PROBLEM

  • Keep the interface legible from across a counter

User Research

Observed a dinner-rush shift and interviewed 3 servers and a kitchen manager about their pain points.

05 / RESULTS

Results

1

Screen replacing multiple tools

3

Color-coded table states
